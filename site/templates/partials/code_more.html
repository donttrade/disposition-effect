Scripts that build this site’s tables

site/learn_tables.py computes the drawdown recovery table and the losing-streak table on the Learn pages when the site is built, and writes the CSV of each. It is in the same public repository, github.com/donttrade/disposition-effect, under the repository’s MIT licence. The site’s tests recompute every value a second way.
