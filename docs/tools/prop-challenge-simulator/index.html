Prop-firm challenge simulator

Most challenge simulators ask for a win rate and an average win and loss, then invent trades from them. This one can start from your own record.

Drop a trade file and it builds 10,000 simulated challenges by drawing whole trading days from your history at random, so a day with three quick losses stays a day with three quick losses, which is what daily loss limits react to. Enter the rules you face: profit target, daily loss limit, maximum loss as a static or trailing limit, time limit and minimum trading days. The result shows the share of runs that passed, busted or ran out of time, and how many busts came after two or more losses in a row. No file? A manual mode takes the usual summary numbers instead. The random seed is fixed, so the same inputs always give the same answer.

This is a simulation of your past trades, not a prediction. It runs entirely in your browser: the page’s security policy blocks every outgoing request.

How each run works

  1. Each simulated day is one of your past trading days, drawn at random (a day can be drawn more than once), with its trades replayed in their real order. In manual mode each day is the number of trades you entered, each a win or a loss at your win rate.
  2. After every trade, the run busts if the day’s loss reaches the daily limit, or if the balance reaches the maximum-loss floor. Reaching a limit counts as breaking it.
  3. At the end of each day, a trailing floor moves up to the highest end-of-day balance minus the maximum loss. Then the run passes if the balance is at or above the target and it has traded the minimum number of days.
  4. A run that neither passes nor busts within the time limit has run out of time.

Only closed trades are in a trade file, so the simulation sees each trade’s final result, not how far it went against you while open. A limit that a firm checks on open positions can break earlier than shown here.

Questions

Is this a prediction of whether I will pass?

No. It shows how your past trading days would have fared under the rules you entered if they came in a different order. Future days can differ from past ones, and past results do not predict future results.

Why resample days instead of single trades?

Daily loss limits depend on how losses bunch within a day. Drawing whole days keeps that bunching, while drawing single trades would spread a bad morning across many days and make daily limits look safer than they were.

How many trading days do I need in the file?

The simulation runs with any number, but with fewer than 30 trading days the page warns that the results lean heavily on a few days. More history gives a steadier picture.

Why are my results the same every time?

The random number generator uses a fixed seed, so anyone can reproduce a result from the same inputs. Change the seed to see how much the answer moves.

Which firms’ rules does it include?

None are built in or named. Enter the numbers from your own firm’s current rules, because rules change and vary by account type.

Is my file uploaded?

No. The file is read in this tab and all 10,000 runs happen in your browser. The page’s security policy blocks outgoing requests.
