Trade stats from your own trade file

Drop the trade file your platform already exports and get the core numbers in seconds: net result, win rate, average win and loss, profit factor, mean result per trade, largest drawdown, and your longest winning and losing streaks. It reads MT5 and MT4 HTML reports, IBKR Flex Query trade files and Tradovate order exports (all three in beta), and a plain CSV template.

Everything is calculated inside this browser tab. The page’s security policy blocks every outgoing network request, so your file is not uploaded anywhere; you can watch your browser’s network tab to check. A ‘real or noise’ check for three of the numbers is coming soon. No sign-up, no cookies, no ads.

The CSV template

One row per fill, with these columns in any order: Date (yyyy-mm-dd), Time (hh:mm:ss), Symbol, Side (Buy or Sell), Quantity, Price. Optional: Currency and Fees. A file with one row per round trip (open time, close time, symbol, direction, volume, open and close price) is read too.

How the numbers are counted

  • A trade runs from flat to flat on each symbol: it opens when your position leaves zero and closes when it returns to zero. A fill that crosses zero closes one trade and opens the opposite one.
  • Results are net of fees when the file has them. Positions still open at the end of the file are left out, and the page says how many.
  • Times are read exactly as written in the file, so results are the same in every time zone.
  • Drawdown is measured on closed-trade equity: the largest fall from a previous high after any trade closed.

Questions

Is my trade file uploaded?

No. The file is read and analysed by code running in this browser tab, and the page’s security policy blocks it from making network requests. Open your browser’s developer tools, choose the Network tab, and watch it stay empty during the analysis.

Which files does it read?

MT5 and MT4 history reports saved as HTML, IBKR Flex Query trade files and Tradovate order exports (all in beta), and a CSV with one row per fill or per round trip. If your platform is not listed, copy your trades into the CSV template above.

What is a good profit factor?

Profit factor is gross profit divided by gross loss; above 1 means the trades in the file made more than they lost. There is no universal good number, and a high figure from a small sample is often luck. If there are no losing trades the page says so instead of printing a number.

Why do my numbers differ from my platform’s report?

The tool counts a trade from flat to flat on each symbol, takes fees off the result when the file includes them, and leaves out positions still open at the end of the file. A note on the results says when rows were skipped or hedged positions were found.

Is this investment advice?

No. It measures your own past trades and does not recommend any security, trade, size or exit. Past results do not predict future results.
